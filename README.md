# Bunker_EF
Присоединяйтесь к модифицированной онлайн игре "Бункер". На планете произошла глобальная катастрофа. Игроки оказались на входе в бункер, где можно пережить самый опасный период. Однако мест и ресурсов хватит только на 5 человек. Задача каждого игрока убедить остальных в том, что именно он должен попасть в бункер. Удачной игры!
